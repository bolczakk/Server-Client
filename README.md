# Rust Multiplayer Server 🦀 and client in OpenGL

Ten projekt to wydajny serwer gier typu multiplayer napisany w języku Rust oraz klient w C++

## 🚀 Funkcje
* Obsługa wielu połączeń UDP (w planach dodanie TCP do niektórych procesów)
* Odbieranie pozycji graczy z klienta napisanego w C++ z asio i rozsyłanie ich do pozostałych
* Wizualizacja wszystkiego w 3D w OpenGL

## 🛠️ Wymagania
* Rust
* Cargo
